gemini.ops.failedrows

FailedRows: the array counterpart of Failed, one failure per failing row.

A check that fails on some rows of an array, inside an @ops.physics function, cannot raise if where is to drop the rows of a branch it does not select. When the caller asked for it (marking, which the eager executor does), the check instead records RowFailures: for each row the number of its first failing check and, for each such check, how to build that row’s exception. The function’s results leave it as FailedRows, an ndarray that carries the RowFailures through gemini.ops and plain NumPy arithmetic (the lowest check number of the operands wins, as in Failed.record). where keeps the failures of the selected branch of each row. A value without a failing row is never a FailedRows, so the clean path has no subclass. An array has the rows on its first axis; any other array carries nothing.

A check outside every physics function (inline in forward) raises, with the failures of all its rows in error.failures so that a caller can leave those rows out and run the others.
