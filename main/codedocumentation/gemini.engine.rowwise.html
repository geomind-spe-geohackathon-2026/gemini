gemini.engine.rowwise

Call a module for real, row by row, and stack the results of the rows into arrays.

call_rows calls module(streams) for each row, and for a stepped module (one with states) scans the rows in time: ops.control.scan carries the state from row to row and each step is module.step(state, dt, streams), the one implementation of forward followed by update. feeds maps <port>.<field> to the column of an inlet field and a dotted control or boundary path to its column; the controls and boundaries are validated and put back after the call, because persisting inputs is the caller’s business. A row that raises is a failed row with that exception (its values NaN), and the state carries over it unchanged. The rows are real ModuleResult trees, so children and the combinations of a plant are exact; stacked joins them into one tree of arrays.
