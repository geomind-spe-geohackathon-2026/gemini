gemini.study

Search and sample plant designs through the public run functions.

Modules

calibrate(plant, dataset, params[, start, ...])

Fit measured outputs with bounded least squares through the public replay API.

evolve(plant, case, objectives, evaluations, ...)

Return the best structures and designs of a superstructure, by a genetic algorithm.

kinds()

Return the kinds of study, each with a title, a description and its settings.

minimize(plant, case, objective, ...[, ...])

Return the design of a plant that minimises a metric, searched in the space the plant states.

result

The result of Study.run: every run's verdict and metrics, the comparison, the best plant.

sample(plant, case, metrics, samples, seed, *)

Return the spread of metrics when the uncertain values of the case are drawn at random.

sensitivity(plant, case, metrics, *[, plan, ...])

Return how each metric changes when each uncertain value of the case moves, one at a time.

size(plant, case)

Return a new plant with first sizes from the case; the plant itself is not changed.

study

gm.Study: the arguments of the study functions as a file, and the run that calls them.
