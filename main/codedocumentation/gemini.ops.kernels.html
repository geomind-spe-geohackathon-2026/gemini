gemini.ops.kernels

The kernels that evaluate ops: python for scalars and numpy for arrays.

select(values) picks the backend of gm.runtime.settings(backend=...) when one is set, otherwise NumPy for array arguments and Python for scalars. An op missing in a backend runs on NumPy. forced_name() is the cheap test of whether a setting is active: ops on plain Python scalars skip the backend selection entirely when it returns None.

Modules

numpy

Array backend: NumPy ufuncs over whole time series, with floating-point warnings silenced.

python

Scalar backend: plain Python operators on floats, NumPy scalars and bools.

scalars

The mode of the eager scalar scope, below the ops so that constants and backends can read it.

solvers

Root finding on arrays for the NumPy backend, step for step like the scalar algorithms.
