gemini.units.shapes

The three shapes of every public return: value, problem and check.

Every public return that carries data is built from these, by the helpers here, so no module assembles a shape by hand. Each shape has a JSON Schema, written to docs/schemas/.

  • Value {value, unit}: a number, an array or None, and when it is None a reason says why. A time series adds time; statistics are {min, max, mean}, each a value. In Python a result of gm.evaluate or gm.study is a Value, a gm.units.Quantity that also holds the reason and the parts of the result; to_dict gives the JSON form that value builds.

  • Problem {path, code, message, suggestions}: every error, validation result and failed run row; a run row adds time. code is the stable key for machines. problem is defined in gemini.errors, a leaf package, because GeminiError.to_dict returns one. This is the public return shape and keeps its name; the input of a run is a gm.Case, never a problem.

  • Check {name, passed, value, limit}, where value and limit are values. A failed check is an answer, not an error.
