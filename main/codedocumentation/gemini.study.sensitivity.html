gemini.study.sensitivity

gemini.study.sensitivity(plant, case, metrics, *, plan=None, on_progress=None)[source]

Return how each metric changes when each uncertain value of the case moves, one at a time.

gm.check runs first and raises its issues. The values are those the case declares an uncertainty for (missing_value when it declares none); plant parameters are not moved. Each is run at its low and at its high end, the others at their values in the case: min and max when the declaration has them, else value - std and value + std of a normal. A run is a copy of the plant and the case simulated on the case, as in minimize. The plant and the case themselves are not changed. With gm.runtime.settings(processes=n) the runs go to n worker processes and give the same result.

Parameters:

  • plant (Plant) – A plant with parameter values.

  • case (Case) – What the plant is asked to do, with the uncertainty of the values to move.

  • metrics (list of str) – The metrics to read, as for minimize.

  • plan (DataFrame, optional) – The run input held fixed, for a building block with no demand.

  • on_progress (callable, optional) – on_progress(done, total) after each finished run, as for minimize; total is the two ends of every uncertain value. Raising gm.errors.Cancelled from it stops the study.

Returns:

A list with one row for each uncertain value and metric, {parameter, metric, low, high, at_low, at_high, effect, feasible_low, feasible_high}: parameter is case.<path>, low and high are Quantity values in SI, at_low and at_high the metric as a Value there, and effect the size of their difference, a Value that is None with a reason when a run failed. feasible_low and feasible_high say whether the run at each end is feasible by gm.evaluate.verdict (False for a run that failed); the numbers are those of the run either way, and a result stored before the flags has none. The rows are grouped by metric in the order given, the largest effect first, the failed last. to_frame() gives the table and to_dict() plain JSON.

Return type:

Tornado
