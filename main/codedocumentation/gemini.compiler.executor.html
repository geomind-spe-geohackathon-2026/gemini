gemini.compiler.executor

The graph executor: trace a plant once, then run whole time series of it.

compile(plant) (compile.py) returns the GraphExecutor of plant, which the engine runs when it is built with compile=True. The executor keeps the traced graphs in the process-wide GraphCache (graph_cache), which holds a graph by the structure of the plant: a second executor, a second engine and a copy of the plant with other numeric values trace nothing again until a guard of the cache changes. A prepared call keeps the plant it was prepared for, and the graph is evaluated for that plant.

A stepped call of a stateful plant is one scan over the rows: context holds the step length of each row (dt) and the state tree the first row starts from (states), and the result holds the state tree after the last row that worked.

Classes

GraphExecutor(cache)

Run a module as a computation graph: trace once, evaluate over all the rows.
