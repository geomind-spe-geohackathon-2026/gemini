gemini.errors.rows

The record of a row of a run that gave no result: one shape, one code, built in one place.

A row is a tick of a run, for one module. It fails when the module raises, a bound leaves its limits or an inlet breaks the stream limits, and it is skipped when a bound column has no value. Either way the run goes on and the row is a problem (gm.errors shape {path, code, message, suggestions}) with the time of the tick and a code of gm.errors.ROW_CODES. The engine builds these records from the exceptions of an executor (eager or compiled, the exception is the same), Results.errors lists them and gm.evaluate.failures groups them: SKIPPED tells the two kinds apart.
