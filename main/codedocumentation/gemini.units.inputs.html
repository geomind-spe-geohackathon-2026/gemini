gemini.units.inputs

The one reader and writer of the shared formats of the input files (Appendix A, section 3).

Every reader takes the value, its path and a list issues, appends an Issue for each thing wrong and returns None when it found any, so one pass over a file reports everything. The caller raises once at the end with gemini.errors.base.raise_issues. to_json writes any object of this module in the form it was read: the unit and the numbers the user gave come back unchanged, the SI value is derived (Leaf.si).
