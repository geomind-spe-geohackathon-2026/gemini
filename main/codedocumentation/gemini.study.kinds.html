gemini.study.kinds

gemini.study.kinds()[source]

Return the kinds of study, each with a title, a description and its settings.

Returns:

{kind, use, title, description, settings} in a fixed order: the methods of gm.Study (run, minimize, sample, sensitivity, evolve, use "method", the value of the method key of study.json) and size (use "prepare", an entry of its prepare list). title and description are plain words for a user. settings is the JSON Schema (draft 2020-12) of the keys the kind reads besides cases and plants: objective, evaluations and seed for minimize, metrics, samples and seed for sample, metrics for sensitivity, objectives, evaluations, population, seed and polish for evolve, none for the others. required lists those the kind cannot do without; objective lists the metrics worth minimising (gm.evaluate.metrics()) and metrics those that a study reads (gm.study.metrics()). Plain JSON, a new list on each call.

Return type:

list of dict
