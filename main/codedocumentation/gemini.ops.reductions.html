gemini.ops.reductions

Reductions over the last axis and interpolation: sum, mean, cumsum, interp.

A reduction takes a time series (an array) on the NumPy backend and a Python sequence on the Python backend. interp(x, xp, fp) is numpy.interp: xp increasing, the end values held outside its range, the same bits on a scalar x as on an array.

Functions

cumsum(values)

Return the running sums over the last axis.

interp(x, xp, fp)

Return the linear interpolation of the points (xp, fp) at x.

mean(values)

Return the mean over the last axis.

sum(values)

Return the sum over the last axis.
