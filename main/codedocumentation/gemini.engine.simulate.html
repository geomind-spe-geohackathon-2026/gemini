gemini.engine.simulate

One run in one call: gm.simulate, gm.replay, gm.live and gm.resume.

Each function builds an Engine, calls the matching method and returns its Results; the run logic is the engine’s, and the engine stays public for what one call cannot do: a run held in memory, a callback that reads it, a manual checkpoint. No object is kept between calls. The plant holds what the compiler traced, so a second call on one plant does not trace it again.

Functions
