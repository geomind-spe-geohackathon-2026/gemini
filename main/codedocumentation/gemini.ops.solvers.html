gemini.ops.solvers

Root finding as ops: brentq and newton, evaluated on floats, arrays and in a graph.

A solver replaces a call to scipy.optimize.brentq or a handwritten Newton loop inside physics. The function to solve is passed to the op, which calls it later with concrete values: on the Python backend with floats, on the NumPy backend with arrays of the rows still iterating, each row stopping by its own rule. In a trace the solver records one solver node whose operands are the bounds (or the start) and args, and whose attributes hold the function and the settings.

The function may not close over traced values. It must be a module-level function, or a nested one that captures only plain constants, and it is written with ops. Everything that varies goes through args, which become node operands:

def _saturation_residual(point, vapour_pressure):

return saturation_pressure(point) - vapour_pressure

ops.brentq(_saturation_residual, low, high, args=(vapour_pressure,), xtol=1e-9)

A lambda point: saturation_pressure(point) - vapour_pressure that captures a traced vapour_pressure cannot be called by a graph and is wrong. Bounds, start and args may be floats, arrays or traced values.

A solve that fails (no sign change of the bracket, no convergence, a non-finite iterate) gives NaN instead of raising, so that an unselected branch of where never raises; follow the solver with a where and a check to give the failure its error. The Python backend is exactly scipy.optimize.brentq and the handwritten Newton loop; the NumPy backend repeats the same iterations on all rows with a mask (see gemini.ops.kernels.solvers).

Module Attributes

BRENT_RTOL

scipy.optimize.brentq's default and minimum relative tolerance, four machine epsilons.

Functions

brentq(function, low, high[, args, xtol, ...])

Return the root of function(x, *args) between low and high by Brent's method.

newton(function, start, derivative[, args, ...])

Return the Newton iterate of function(x, *args) from start, NaN if it fails.

wegstein(current, image, previous, ...)

Return the next iterate of one field by Wegstein's method, per element.
