gemini.modules.check

gemini.modules.check(cls, example=None)[source]

Return a report of gemini’s module rules for a new Module class; it never raises.

The checks, in order: is_module (a subclass of Module), instantiate (cls() declares without error, which also enforces the declaration rules: Stream ports, valid bounds, no clashing names), category (one of gm.modules.categories()), forward_signature (exactly forward(self, inputs, inlets, state)), units (every numeric scalar parameter, control, boundary and output is declared with a quantity type that has a unit; coefficient arrays are exempt), describe (describe() returns plain JSON) and call (one call through gm.call with the example values runs). Any exception a check meets, including one raised by the class itself, becomes a failed check with its message.

Parameters:

  • cls (type) – The class to check.

  • example (dict, optional) – Values for the call check, the arguments of gm.call: {"parameters": {...}, "inlets": {...}, "controls": {...}} and, for a module with state, "state" and "dt", with quantities for the values with a dimension, as gm.call takes them. Without it the call uses the declared defaults, and a module that needs a value gets passed None.

Returns:

Plain JSON {module, passed, checks}: module is the class name, checks a list of {name, passed, message} where passed is True, False or None (could not be decided), and passed is False if any check failed, otherwise True.

Return type:

dict
