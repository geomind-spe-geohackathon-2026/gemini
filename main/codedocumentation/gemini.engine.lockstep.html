gemini.engine.lockstep

Many runs side by side: answer the executor requests of several runs together.

A run is a generator of Request objects (gemini.engine.executor). lockstep starts the runs one after the other, collects the request each one stops at, hands the requests that an executor can batchable evaluate together to its run_batch (one array pass for all of them), runs the others alone, and sends each run its answer. Each run goes on in a context of its own, so the runtime settings it enters are its own. A restore function of a run is called before the run goes on and before a request of it that runs alone, for runs that share a plant. A finished function, when given, is called with each run as it ends.

Functions

lockstep(lanes[, finished])

Run the lanes to their end and return the value of each one's generator.
