gemini.case.missing

gemini.case.missing(case)[source]

Return what a case does not have yet: the paths a form still has to ask for.

It reads a Case or a plain dict that is not complete, which Case.from_dict would refuse, and never raises. It lists what the file needs by itself: the header (format, kind, name), the three keys of time, the leaves that a section requires when the section is given (the power of a service), the header of an economics given in the case, and the keys of each requirement. What a plant needs from the case (a ground temperature, a price) depends on the plant: gm.check(plant, case) lists it once the case reads.

Parameters:

case (Case or dict) – A case, or a case document, possibly without parts. A part given as the path of a file is not looked into; anything that is not a mapping counts as an empty document.

Returns:

One Issue of kind missing per value, in the order of case.json: path the place in the document, quantity and accepted the quantity and the units of a value with a dimension (time.step is a duration), the other two empty. The same shape as Case.check(); an empty list means that nothing the file itself needs is absent.

Return type:

list of Issue
