gemini.compiler

The compiler: trace a plant into a computation graph and register it as an executor.

Importing this package registers compile as the executor an Engine built with compile=True uses (gemini.engine.executor.register_executor); nothing else in the package depends on it. compile(plant) returns the executor of a plant. The design is described in .claude/docs/native-engine.md.

Modules

cache

GraphCache: traced graphs by the structure of a module, retraced only when it changes.

compile(plant)

Return the executor that runs plant through its computation graphs.

executor

The graph executor: trace a plant once, then run whole time series of it.

ir

The intermediate form: a computation graph of nodes, its loop bodies and its inputs and outputs.

passes

Graph passes: rewrites of a traced Graph that keep its results and its errors.

run

Run one module over whole time series: run_graph plus a raise.
