gemini.compiler.run

Run one module over whole time series: run_graph plus a raise.

run(module, inlets, inputs) is the prototype’s stand-in for the engine integration. Inlets are Stream objects whose fields are arrays over time (validated when built); inputs maps control and boundary names to arrays or scalars, and the module’s persisted values fill the rest. Parameters and constants come from the module and the graph. It is a thin form over run_graph: the graph (a root break when the module cannot be traced, its reason in Run.breaks) is evaluated on the backend you name and the first failing row raises its exception. The row count is the longest array among the inlet fields and inputs, one without arrays.

graph_feeds gives the value of every graph input; the engine uses it with run_graph.

run_function(function, *args, **fixed) does the same for a plain function (a physics function, a module’s helper): the numeric positional arguments become graph inputs, the function is traced once on them, and the graph is evaluated on the arguments, so an array argument crosses where and check like a column of a run instead of raising at its first failing row in the function body.
