gemini.ops

Ops that physics is written with, so one function runs on floats, arrays and traced values.

Arithmetic and comparisons come from the Python operators of the values themselves; the functions here cover what operators cannot express: where instead of a value-dependent if, check instead of if ...: raise, logical_and, logical_or and logical_not instead of and, or and not, maximum, minimum and abs instead of max, min and abs, and the functions of math (log, sqrt, exp, …), reductions, interp and the solvers brentq and newton. Constant declares a named constant that a trace records as a graph input. physics decorates a public function of gemini/physics so plain operators are safe in an eager call (see gemini.ops.scope); Failed is the value of a function whose check failed there.

Modules

backend

The Backend base class, the backend registry and the context-local backend setting.

check(condition, error, message[, code])

Raise error(message.format(**values), code=code) where condition fails.

control

scan: time stepping with a carried state, one step after the other.

dispatch(name, *operands[, attributes])

Apply the op name to operands: record it on traced values, else evaluate it.

elementwise

Elementwise functions and operators of the physics: exp, log, sqrt, maximum, ...

failed

Failed: the value of a physics function whose check failed in an eager scope.

failedrows

FailedRows: the array counterpart of Failed, one failure per failing row.

kernels

The kernels that evaluate ops: python for scalars and numpy for arrays.

logic

Comparison ops, logical_and and where, the branch choice of traced physics.

math

Arithmetic ops and vector indexing; truediv, pow, mod and floordiv never raise.

reductions

Reductions over the last axis and interpolation: sum, mean, cumsum, interp.

registry

The op registry: the name, kind and operand count of every op.

scope

The eager physics scope: @ops.physics and the scope a module call enters.

solvers

Root finding as ops: brentq and newton, evaluated on floats, arrays and in a graph.
