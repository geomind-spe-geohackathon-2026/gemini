gemini.ops.failed

Failed: the value of a physics function whose check failed in an eager scope.

ops.check cannot attach an error to a value it returns nothing for. On concrete scalars it raises the real error marked as coming from a check (mark); ops.physics catches a marked error at the function’s boundary and returns Failed(error) instead, so that where(stopped, 0.0, checked_function(x)) drops the error when stopped selects the other branch, exactly as the graph’s error codes do. A Failed is a Symbolic: every op, operator, Constant and NumPy scalar operation that meets it returns it. where is the exception: a concrete condition selects a branch and an error in the other branch is dropped, while a Failed condition stays failed. bool(), float(), int() and format() raise the error, so a structural if, a Stream or a Declaration surface it, and so does leaving the outermost scope (ops.scope.plain).

Functions

is_marked(error)

Return whether error was raised by a failing ops.check.

mark(error)

Mark error as raised by a failing ops.check and return it.

Classes

A value that stands for a failed check; error is the exception it raises if used.
