gemini.errors

The seven error classes, GeminiWarning and the fixed code lists, as gm.errors.<Name>.

What a former class meant is a code: CODES and ROW_CODES are the fixed lists. A built-in base appears only where Python needs one: ValidationError is a ValueError, and the private classes of gemini.errors.lookup add KeyError and AttributeError for hasattr, getattr with a default and mapping lookups. Nothing in this package imports from the rest of gemini.

Modules

base

The seven error classes, the warning, the fixed lists of codes and the shape of a problem.

lookup

ValidationError for Python's protocols; private, never in gm.errors.

rows

The record of a row of a run that gave no result: one shape, one code, built in one place.
