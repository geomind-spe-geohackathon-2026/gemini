gemini.ops.control

scan: time stepping with a carried state, one step after the other.

scan(body, init, xs, length) calls body(state, x) for each of length steps, carries the state it returns to the next step and collects what it returns for each step. A step that fails (body raises) is a failed step: its values are NaN, its error is kept, and the next step starts from the state before it, so a failed step never advances the state. In a trace the call records a scan node of the graph (Graph.scan); outside one it runs the loop, which is the reference of every other implementation.
