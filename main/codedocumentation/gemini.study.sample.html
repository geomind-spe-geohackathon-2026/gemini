gemini.study.sample

gemini.study.sample(plant, case, metrics, samples, seed, *, plan=None, on_progress=None)[source]

Return the spread of metrics when the uncertain values of the case are drawn at random.

gm.check runs first and raises its issues. The distributions are only those the case declares (uncertainty next to a number of site, demand, utilities or economics in case.json); a case with none raises missing_value. Plant parameters are design decisions and are never drawn. Each draw copies the plant and the case, sets the drawn values on the copy of the case, simulates the copy (gm.simulate plans the demand on that design) and reads the metrics. The plant and the case themselves are not changed. With gm.runtime.settings(processes=n) the draws run in n worker processes and give the same result. A draw that breaks the bounds of a value of the case, such as a negative price, is a draw whose run failed.

Parameters:

  • plant (Plant) – A plant with parameter values.

  • case (Case) – What the plant is asked to do, with the uncertainty of the values to draw. A uniform is drawn between its min and max, a triangular with the value of the case as mode, a normal around the value, redrawn until inside its bounds if it has any. A profile of the case becomes the drawn constant.

  • metrics (list of str) – The metrics to record, as the objective of minimize without a sign.

  • samples (int) – The number of random draws, one simulation each. It has no default.

  • seed (int) – Seed of numpy.random.default_rng, 0 or more; the same seed gives the same draws. A seed is a reproducibility choice, so there is no default.

  • plan (DataFrame, optional) – The run input held fixed over the draws, as for minimize.

  • on_progress (callable, optional) – on_progress(done, total) after each finished draw, as for minimize; total is samples. Raising gm.errors.Cancelled from it stops the study.

Returns:

A dict {samples, summary}: samples lists each draw’s parameters, Quantity values in SI by case.<path>, and metrics, a Value per metric, with a reason for a draw whose run failed, and feasible, whether the run of the draw is feasible by gm.evaluate.verdict (False for a run that failed); a result stored before the flag has none. The flag does not change the metrics or the summary, which count the draws as before; summary gives, for each metric, {mean, p5, p50, p95} over the draws that give a finite number, each a Value that is None with a reason when none does, and failed, the number of draws left out because their run had failed steps (their reason names the count and the most frequent failure). to_dict() is plain JSON; Sample.from_dict reads it back.

Return type:

Sample
