gemini.engine.archive

Results as one .npz archive: typed arrays for numeric columns, JSON text for the rest.

A column that is a float, integer or boolean array is stored as that array, so every bit survives. Any other column (lists, strings, None, mixed cells) is one JSON text holding the list of its cells; Python writes floats in JSON with the shortest text that reads back as the same number. The metadata is one JSON text too, so the archive loads with allow_pickle=False.
